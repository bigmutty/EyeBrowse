👁 EyeBrowse

Settings for gaze / mouse dwell activation of links and clickable elements.

General

When an input, textarea, or editable area is focused, a large keyboard appears so you can type by dwelling on keys.
How long the cursor must stay over an element before it is activated. Typical values: 800–1500 ms.
Prevents accidental double-activations right after a click.

Site filter

Enter hostnames only (no https://). Subdomains match automatically (e.g. example.com also matches www.example.com). Leading *. is optional and ignored.

Tobii WebSocket (direct gaze)

Requires a local bridge that streams gaze over WebSocket (e.g. Tobii EyeX / Interaction WebSocket Server on port 8887). When connected, dwell uses gaze coordinates instead of the mouse.
Default: ws://localhost:8887. Other common ports: 8886, 8080.
Status: unknown

Detection

Ignores very small targets that are hard to hit accurately with gaze.
